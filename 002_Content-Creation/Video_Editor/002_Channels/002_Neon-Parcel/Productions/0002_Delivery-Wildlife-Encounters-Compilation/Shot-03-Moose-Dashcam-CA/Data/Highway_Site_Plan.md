# Site Plan — Rural Northern Ontario Highway (text form, before any image)

**Real route, described as a person/vehicle would actually travel it:**
van travels along a two-lane paved rural highway, dense boreal treeline
close on both shoulders, no intersections or buildings in view (Phase 1:
this is a remote corridor, not a town edge). The moose crosses from the
treeline on one shoulder, through the van's lane, toward the opposite
treeline — a single continuous, physically walkable path, no gaps or
teleporting.

## Orientation reference

The van faces forward along its direction of travel (into the page/scene,
away from camera-mount position). The moose, once it turns to face the van
during the pause beat, faces back toward the camera/van — this is the
inverse mirror relationship of Shot 02's car-orientation fact, stated here
explicitly so it isn't left ambiguous the way "backed in" was on that shot.
No jargon shorthand — orientation is always stated by which literal
body-parts/features face which direction.

## Plausibility check against this written plan (not against a generated image)

- **Continuous walkable path:** yes — treeline gap → shoulder → near lane
  → pause point is one continuous route with no gaps or illogical jumps.
- **No blocked path:** no set-dressing element sits between the moose's
  entry point and its pause position.
- **Real-world scale consistency:** lane width (~3.5 m per lane, standard
  two-lane rural highway) is stated so the moose's ~4-5 ft shoulder height
  (Grounding Audit) and the van's hood can both be checked against it as a
  concrete, comparable measurement — not left to visual guesswork.
- **No architectural/construction-logic risk category applies here** — this
  is an open road/natural landscape, not a built structure with
  load-bearing geometry, so the step-count/staircase-offset class of
  defect from Shot 02 has no equivalent risk here. The equivalent risk for
  this location type is treeline continuity and lane-count consistency,
  both addressed above.
