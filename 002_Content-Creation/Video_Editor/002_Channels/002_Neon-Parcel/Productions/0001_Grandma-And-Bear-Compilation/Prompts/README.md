# Prompt Archive

Every paid provider prompt must be saved here verbatim before submission.
Prompt files are immutable and versioned by shot. Each file must include the
provider, model, resolution, reference assets, generation parameters, and the
provider task ID once it exists.

The first batch predates this rule, so its exact provider payloads are not
available for reconstruction. The saved shot descriptions remain in
`Scripts/Shot_List_v2_Review_Batch.md`.
