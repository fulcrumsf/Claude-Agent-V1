## generate_youtube_package.py title/description builder is broken — bypass it
`build_titles()` and `build_description()` in `generate_youtube_package.py` produce broken output: `.title()` mangles apostrophes ("Anglerfish'S"), long subject strings get silently truncated mid-word inside title strings, and hashtags concatenate the full subject with no delimiter. Passing a full-sentence subject (as I initially did) made this much worse.
- **Fix applied this session:** hand-write titles/description directly instead of calling `build_titles`/`build_description`. Keep `subject` short (a noun phrase) if the functions are ever reused, but preferred approach now is bypassing them entirely for quality copy.
- **Not yet fixed in the script itself** — flagging as a known bug for next time someone touches `generate_youtube_package.py`.

## Blotato presigned uploads require an explicit Content-Type header
`curl -X PUT --data-binary` against a Blotato presigned upload URL with no `-H "Content-Type: ..."` header uploads the file as `application/x-www-form-urlencoded` regardless of actual file type. `blotato_create_post` then fails with a cryptic, misleading error: `"Failed to fetch media URL: char 'e' is not expected.:1:1"` — this is NOT a media-URL-unreachable error, it's Blotato's backend choking while trying to parse the wrongly-typed file.
- **Fix:** always pass `-H "Content-Type: video/mp4"` (or `image/png`, etc.) explicitly on the PUT upload step for both video and thumbnail. Verify with `curl -I <publicUrl> | grep -i content-type` before calling `blotato_create_post` if a post fails with that error message.
- **Why this matters:** this will recur on every future Blotato local-file upload (RR, NeonParcel, etc.) unless the header is set every time — worth checking `upload_to_blotato.md` docs across channels to see if they need the same fix noted.

## Blotato has a 400MB video upload cap
V6 of the Bioluminescence Weapon video was 944MB (18.5Mbps 1080p) and failed upload with "File exceeds the maximum upload size (400 MB) for your plan." Compressed via two-pass ffmpeg to ~6.3Mbps target bitrate → 330MB, which uploaded fine at visually comparable quality for a documentary-style video.
- **How to apply:** before uploading any future video via Blotato, check file size against the 400MB cap. If over, two-pass encode targeting ~6.3-7Mbps (1080p30) lands comfortably under with good quality. Keep the original high-bitrate render untouched — only the upload copy gets compressed.
