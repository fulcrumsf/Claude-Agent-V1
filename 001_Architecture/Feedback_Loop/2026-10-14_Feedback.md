# Feedback Loop — 2026-10-14

## Tool-category research must check Resource Library bookmarks + broad web search, not just find-skills

Tony's exact words: "the agent that you sent out to do the research is useless. How can we fix that? I don't need useless agents because then I'm not getting the correct answers or output from you." Triggered when he asked about Agent Reach, NexLev, and Kalodata/FastMoss — all found in under 5 minutes with a plain grep + web search, none of which the 2026-10-13 Ikigai tool-research pass surfaced.

**Root cause, specific not vague:** that research pass used `find-skills` (Claude skill marketplace search) plus lookups on tool names already known, and reported coverage as complete. It never (1) grepped `007_Resource_Library/Tools/` for the topic — Agent Reach was bookmarked there 2026-09-13, over a month before the research ran — or (2) ran a single broad category web search ("best TikTok Shop analytics tools 2026," etc.). Both would have surfaced everything immediately.

**Why it matters:** a tool-research pass that skips the person's own bookmarks and never broadens past named lookups isn't actually research — it just confirms what was already known going in. This is the same class of failure as `feedback_verify_before_presenting` (grounded ≠ verified) and `feedback_real_data_over_opinion_scoring`, applied to tool discovery specifically.

**Fix applied, 2026-10-14:** added an explicit "External Tool/SaaS Discovery Protocol" section to `001_Architecture/Skills/Tool-Manager/SKILL.md` (the skill already mandatory-auto-invoked before any tool-availability question) naming the two required steps in order: grep the Resource Library + Wiki first, then run genuine broad category web searches — never let a `find-skills`-only pass stand in for tool research.

**How to apply going forward:** any "what tools exist for X" question — whether answered directly or delegated to a subagent — must do local-bookmark-check + broad-web-search before reporting coverage complete. If delegating this kind of research to a subagent, the prompt handed to it must explicitly include both steps; don't assume the subagent will infer them.
