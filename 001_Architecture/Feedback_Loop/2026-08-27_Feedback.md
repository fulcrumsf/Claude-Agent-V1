## Shot 1 Causal Dialogue Lesson

- Shot 1 failed because Grandma says the bear refuses dry food even though no
  feeding is occurring and the officer did not mention feeding. The line has
  no causal connection to the visible exchange.
- Dialogue must be grounded in the immediate action and conversational setup.
  If the officer says, "Ma'am, that's a wild animal," while Grandma is not
  feeding the bear, a believable reply is closer to, "Well, he ain't hurting
  nobody." If Grandma is actively feeding it and the officer objects, then the
  dry-food response becomes contextually coherent.
- This is a learning note for the current review process, not yet a global
  skill update.

## Shot 2 Storyboard Interpretation Lesson

- A six-frame storyboard is a sequence of visual continuity checkpoints, not
  the finished video's visual format. The generated result must be one
  continuous 16:9 video, not a six-panel storyboard or a shot that visibly
  imitates a storyboard layout.
- The reference lock applies to camera style, angle, lens character, framing,
  geography, lighting, fixed geometry, and ordered action continuity. It does
  not mean reproducing the storyboard panels as frames on screen.
- This is a learning note for the current review process, not yet a global
  skill update.

## Shot 3 Subject-Count Continuity Lesson

- Shot 3's primary event was acceptable, but a second car carrying a second
  bear entered immediately after the first car passed. That was not intended;
  the shot should contain one filmed passing event and one bear.
- The cause cannot be identified confidently because the original provider
  prompt was not archived. Future prompts must state subject-count limits and
  explicitly end the event after the single vehicle exits frame, then preserve
  the exact prompt for audit.
- This is a learning note for the current review process, not yet a global
  skill update.

## Shot 3 Keyframe Endpoint Lesson

- A second contributing cause may be that the start and end frames were too
  similar and both retained the car-and-bear subject. For a single passing
  event, the end frame may be stronger if it shows the vehicle leaving frame
  or no vehicle at all, giving the interpolation a clear endpoint.
- Start/end frames must communicate temporal change, not merely duplicate the
  same composition. This remains a hypothesis until the original prompt and
  exact provider inputs are available.
