# Feedback Log — 2026-05-18

## [HARD RULE] Never write API keys into local .env files

**What happened:** When installing video-use, the ElevenLabs API key was read from `~/.env-secrets` and written directly into the tool's `.env` file. Tony corrected this immediately.

**Rule:** `~/.env-secrets` is the single source of truth for ALL API keys across the entire workspace. No key values ever get written into local `.env` files, regardless of what the tool's install instructions say.

**Correct behavior:** If a tool requires a `.env` file to exist, create it with a redirect comment only:
```
# API keys are NOT stored here.
# Single source of truth: ~/.env-secrets
#
# Before running this tool:
#   source ~/.env-secrets
#
# Keys needed by this tool:
#   ELEVENLABS_API_KEY
```

**Applies to:** Every tool installation, every agent, every project — no exceptions. This is a hard-coded workspace rule.
