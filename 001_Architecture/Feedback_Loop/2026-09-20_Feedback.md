# 2026-09-20 — Feedback

## [Corrected] No separate environment-validation video once the environment sheet is already approved

**What happened:** the "Confirmed recipe" locked yesterday (2026-09-19)
included a cheap single-reference, empty-scene Seedance test before the
full multi-reference action shot, meant to catch an environment-level
defect before it got baked into a more expensive call. Tony rejected this
outright when it came up again on Shot 04: once he has already reviewed
and approved the environment sheet as a still image, a video that should
just reproduce that same static scene in motion shows him nothing new and
wastes money.

**Rule:** never run a separate environment-only validation clip once the
environment sheet itself has been approved. Go straight from the approved
environment + character sheets to the full action shot.

**How to apply:** the defect-catching purpose that step served now has to
be covered earlier — review the environment sheet panels carefully (which
this pipeline already does) before presenting them for approval, not by
spending on a second video to re-check what a still image already showed.
Locked into `Seedance-Prompting-Guide/SKILL.md`'s "Confirmed recipe"
section, step 3, superseding the original form of that step.

## [Corrected] "Don't make me approve every step" means run ALL documented steps, then show the COMPLETE deliverables

**What happened:** On Shot 05 Tony said to do everything up to the character sheet and environment sheet without stopping for approval at each step.
