# Feedback Loop — 2026-06-10

## [CORRECTION] AI video prompts must lock spatial orientation of falling objects
When prompting video models (Seedance, Veo3, Omni) for a "deck of cards falling," the model will default to animating the object entering frame on its edge (vertically upright) unless the orientation is explicitly locked.

**What failed:** "drops straight down from above" → Seedance animated the deck entering frame standing vertically on edge, not flat.

**Fix pattern:**
- State orientation before motion: "The deck is ALREADY ORIENTED HORIZONTALLY AND FLAT — parallel to the table surface, card backs facing camera"
- Use a physical analogy: "like a hardcover book dropping face-down onto a table"
- Add explicit negatives: "never rotates, never tilts, never stands on edge"
- Lock orientation relative to camera: "showing the wide face of the deck at all times"

Apply this to any falling/dropping object prompt.
