## Resume From a Known-Bad Fixture

When resuming a multi-phase pipeline, first prove the checker against a known
bad real artifact before connecting paid providers. The Shot 6 storyboard v1
was useful because it visibly demonstrated missing panels, blank captions,
wrong gate state, and broken character continuity.

## Separate Provider Parsing From Approval

The vision provider adapter must only transport and parse model output. The
existing fail-closed QA evaluator remains the authority that decides pass,
fail, or manual review. This separation prevents a provider response from
silently becoming an approved storyboard.

## 0.5s cross-dissolve is the DEFAULT transition — global, all channels

After seeing block A of the Glass Frog revision, Tony: "rather than doing hard cuts
by default the 0.5 cross dissolve works really well ... this should be like a
global thing." Applies to scene boundaries AND internal shot changes (image
swaps, b-roll cuts). Hard cuts only when there's a deliberate reason (a shock
cut, a match cut). Narration/VO audio still joins hard (with a ~3-frame edge fade
to kill clicks) — only the picture crossfades.
