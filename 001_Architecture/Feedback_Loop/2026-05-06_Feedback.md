# 2026-05-06 Feedback

Tony prefers the ChatGPT export to become a human-readable Obsidian brain rather than a raw archive:

- organize `OpenAI_History` by theme folders
- create one readable conversation note per conversation
- keep canonical image assets in `Obsidian_Attachments/OpenAI_Images/Inputs` and `Outputs`
- keep the generated image notes directly in `Research/OpenAI_Images`
- use descriptive filenames with a short ID suffix only at the end
- keep conversation notes linked to related images and similar conversations
- populate the conversation note `## Input Images` section from the saved input index so uploaded images can be found before any later rename pass
- when handling large image sets, create labeled staging boxes/folders that explain what the files are and why they were grouped, instead of making an unlabeled mirror or dumping them into a generic copy folder
- preserve originals and keep an explicit audit trail so the workflow can be backtracked later without relying on filename memory alone
- preferred image-box layout should separate confirmed ingested files, generated outputs, user uploads, documents, exact duplicates, and a needs-review fallback, with a manifest that records the source path and reason for the bucket
- Tony simplified the decision rule further: anything already ingested should go into an `Already-Ingested-Delete-Later` box, and everything else should go into a `Needs-Ingesting` box so the folder name directly tells him what action is left

This preference should guide future ingest and retrieval work so the vault is readable by folder inspection without forcing raw hashes or opaque identifiers into the primary layout.
## OpenAI history folder hygiene
- Tony wants ingest review to use only two human-readable folders: `Already Ingested` and `Needs Ingestion`.
- Tony prefers moving files into the status folders instead of copying them, so the root stays readable and backtracking is clear.
- Tony also wants raw conversation UUID folders grouped under a human-readable label like `Already-Gone-Through-Theme-Process` instead of leaving the UUIDs exposed at the root.
- Tony wants the OpenAI history architecture to be `.md` conversation notes plus links to images stored in `Obsidian_Attachments`, not images embedded in the history tree itself.
