## Neon Parcel: storyboard keyframe fallback (Tony, Claude Code session)
- **Decision:** when a storyboard-reference video tiles/splits and an edge crop can't save it, don't generate new keyframe images — cut the storyboard's own panels out (each at its own border, native ratio, no caption text) and re-run the shot with them as reference images. The storyboard itself is not sent in this mode but is always kept (non-destructive).
- **Slot priority (Tony):** 6 keyframes first, then character sheets, then environment sheet, then props, up to Kie's 9-image limit.
- **Fallback order:** 1) crop edges, 2) keyframe fallback, 3) clean first/last-frame route.
- **Why:** panels already are ordered keyframes; cutting them is free. Official Seedance 2.5 guidance says separate keyframes align better than one grid (not yet proven on Mini).
- **Tony's framing:** 16:9 is the target because that's YouTube's wide format, but keyframe crops keep the panel's native ratio — never force a crop to 16:9.
