# Feedback Loop — 2026-10-18

## Fix and verify before reporting; never surface an unresolved maybe

Tony said repeatedly: "Do not report things that need fixing. Just fix them and come back only when everything is checked and done." Do not say "I haven't done X" when X can be checked. Go verify it, fix what is actually wrong, then report the verified end state.

**How to apply:** audit the live state before responding; resolve suspected issues or establish with evidence that they are not issues. Do not hand Tony a list of maybes as though adjudicating them were his job.

## TikTok is the source of truth; never publish from Printify

Publishing from Printify reset TikTok Shop size charts and brand on 11 listings today, all of which had to be rebuilt. Printify is for catalog and migration work, not the final publish. Make listing changes in TikTok Shop and treat TikTok as the master record.

**How to apply:** never press publish in Printify for these stores. If a listing needs to be recreated, use Printify **External products > Migrate product**, then finish and verify it in TikTok Shop.

## Use a fresh tab for each TikTok Shop edit

TikTok Shop edit pages block navigation with a "Leave site" dialog. Reusing one tab turns routine product work into dialog handling and risks losing edits.

**How to apply:** open a fresh tab per product and close nothing until the work is verified.

## Redirect credential-hook output to a scratchpad, then read the file

The Bash credential hook can block all output from a command that touches credentials. A blocked command is not a failed command.

**How to apply:** redirect the command's output to a scratchpad file, then read that file back. Never work around the hook by printing credentials.

## Do not close browser tabs

Do not clean up by closing tabs at the end of a browser task. Keeping them open preserves the verified state for Tony and makes follow-up checks possible.
