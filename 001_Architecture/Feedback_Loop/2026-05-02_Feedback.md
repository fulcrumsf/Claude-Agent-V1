- Tony realized that routing files by their medium ("Bookmark") creates a useless dumping ground.

## Preference: Flat Folders with Rich Tags over Nested Folders
- Tony prefers keeping folders like `Tools` completely flat rather than creating endless nested subdirectories (e.g., `Tools/Video`, `Tools/Audio`).
- Instead of subfolders, Tony relies on the AI ingest script adding 2 to 5 rich semantic tags (`video-production`, `agentic-ai`) in the YAML frontmatter. This keeps the file system simple but allows powerful queries in Obsidian Dataview or Graphify.

## Validated: Video Knowledge Packages
- Videos are highly valuable but dense. Tony does not want loose `.mp4` files floating around.
- Preference: Every ingested video MUST get its own subfolder wrapper (e.g., `Videos/Descriptive-Name/`), containing the video file, an empty `Transcript.md`, and an empty `Tutorial.md`. This future-proofs the file for AI extraction and monetization later.

### Tie-Break Rules from Tony
- **Preference**: If a screenshot is of Notion and the actual goal is to capture reusable prompt text, route it to `Prompts` and preserve the prompt in the note.
- **Preference**: If a screenshot is of YouTube or TikTok and the content is primarily a walkthrough or tutorial, route it to `Tutorials` and capture the video title, creator, and URL if visible.
- **Preference**: If a screenshot is of a tool, SaaS, GitHub repo, or product page, route it to `Tools`, especially when a URL or captions identify the product.
- **Preference**: `Docs` is for PDFs and text reference material, and only rarely for markdown when the content is specifically API or configuration instructions, such as curl or HTTP request examples.
