## Session: Pompeii video pipeline completion + pipeline lock-in (Jul 4, 2026)

### C20 boat direction — spatial orientation constraints
Tony rejected C20 because the boat moved backwards. The fix: remove all moving subjects from the final shot entirely (no boat, no figures), not just add directional constraints. When a subject's motion is physically constrained and the model keeps getting it wrong, removing the subject is cleaner than adding more prompt rules.

### assemble.py must be universal — never production-specific
Any script that contains hardcoded story-specific values (Suno prompt, caption text, character names) will break the pipeline for new productions. Production-specific config belongs in Production/assemble_config.json. Scripts live in 001_Architecture/Tools/ and take production_folder as argument.

### 8s hard max on clip duration — not 10s
Tony chose 8s over 10s explicitly for engagement reasons (faster cuts = less boredom). The 4s gap to Seedance's 12s max is intentional padding. Do not negotiate this upward.

### Script word count formula — 163 WPM × 1.15
Voice raMcNf2S8wCmuaBcyI6E speaks at 163 WPM (measured from Pompeii). +15% padding is mandatory. Without it, TTS output runs ~15% short of target. Formula: ceil(target_min × 163 × 1.15).

### TTS duration must be validated before proceeding
After ElevenLabs generates narration.mp3, ffprobe the duration. If >5% short of target, stop and flag. Do not silently continue with a shorter video.

### Title hooks, description ranks
- Title = curiosity hook (pattern interrupt, curiosity gap, specificity)
- Description = search intent (first sentence = the exact question someone types into YouTube)
Never swap these roles.

### Thumbnail = composition formula, not palette formula
Tony's pick was Concept C (lone figure walking away through ash-covered dead city). The winning elements: single human back-to-camera, lower third, deep vanishing point, vast atmospheric world. The palette matches the story — do not force dark/ashy on every video.

### Suno API — correct endpoint and required fields
- Endpoint: https://api.kie.ai/api/v1/generate (NOT /jobs/createTask)
- Required fields: prompt, customMode, instrumental, model, style, title, negativeTags, callBackUrl
- callBackUrl is required even when polling — use https://example.com/callback as placeholder
- Response returns array of URLs in resultJson — pick longest by ffprobe duration

## Session: First Blotato upload + CTA/end-screen system + pipeline locked through upload (Jul 4, 2026, later same day)

### CTA gap is audio-only — never a video cut
Tony was very precise about this distinction: "I only want a gap in the audio... I do not want a gap between the videos." The 8-second end-screen hold is one continuous video clip throughout; the audio inside it has a silence gap before the CTA line starts. Conflating "pause" with "cut" would have broken this — they apply to different tracks.

### Static CTA audio over per-video generation
Asked Tony to choose between generating the CTA line fresh via ElevenLabs each video vs. rendering it once as a reusable asset. He approved the static-asset recommendation. Reasoning that landed: guaranteed exact timing every render (no risk of ElevenLabs returning a differently-timed take that overflows the fixed 8s window) and zero added per-video cost. Apply this same reasoning to any other fixed/recurring audio element (intros, transition stingers) if they come up later.

### Playlists stay manual — don't over-automate on the first pass
Even though Blotato's `playlistIds` field exists and all 18 ReimaginedRealms playlists are visible via `blotato_list_accounts`, Tony explicitly wants playlist assignment to stay a manual step for now ("I will add those separately... probably change that to automatic later for time and convenience, but for now let's leave that as the setting"). Don't add automation Tony hasn't asked for yet, even when the capability is sitting right there.

### Verify current MCP tool availability by calling it, not assuming from memory
Session opened with stale assumption that Blotato needed re-registration; the actual issue turned out to be a real gap in `generate_system_map.py` (it never scanned `~/.claude.json`, where Claude Code CLI stores `claude mcp add` registrations). Confirmed via direct inspection of the JSON file rather than trusting the generated System-Map.md. When a generated report and a live tool call disagree, trust the live tool call and go fix the generator.

### Don't let "lock in the memory" balloon into an unrelated reindex
Asked to fully lock in Blotato knowledge into Graphify. Running the full semantic `--update` would have re-extracted ~993 unrelated, pre-existing files due to a stale manifest — completely disproportionate to the actual ask. Stopped and flagged it as a separate hygiene issue instead of burning a large action on scope creep. Correct call — matches the "don't add work beyond what's asked" principle even when a tool's own workflow nudges toward doing more.
