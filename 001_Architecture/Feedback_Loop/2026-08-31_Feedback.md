# Feedback — 2026-08-31

## Diagram camera must hold still while a label/callout is on screen

Watching the Glass Frog (0003) edit, Tony flagged that the DiagramLabels callouts
pop up while DiagramCamera is still panning/zooming the image behind them, so the
label and the feature it points to drift apart.

**Standing rule for all future diagram/infographic builds (any channel):**
- The camera holds **completely still** whenever a label/callout is visible.
- All camera moves are **slow, ease-in AND ease-out** — nothing abrupt.
- Blocking pattern per feature beat: **move → settle → label in → hold → label out
  → move.**
- Labels are never composited over a moving image.
- Constant motion is not required or desired for a static diagram — stillness
  during labels is better.

**Why:** a callout only works if its leader line stays locked on the feature the
whole time it's readable. Motion behind a label breaks that and looks unfluid.

**How to apply:** design the camera keyframes with identical-value "dwell" pairs
bracketing each label's visible window; ease between dwells. Fold into
`001_Architecture/Skills/Diagram-Generation/` and the Anomalous Wild pipeline's
`Diagram_Blocking_Plans.md` spec + Phase 7 diagram static-hold section.

## Diagram label / callout aesthetic — reference-image driven

Tony generated a reference in GPT Image 2 (the "RED BLOOD CELLS (awake)" vessel
diagram, 2026-08-31) as the target look for all diagram labels/callouts going
forward. Key traits: large clean white sans-serif main term; parenthetical
qualifier in a subject-derived accent colour; thin white leader line with one
right-angle bend + end dot; soft glowing halo dot at the feature; optional 2-3
line white description; high contrast via size/weight/glow, no box needed;
restrained editorial "science-doc" tone (not gamer-HUD, not neon).

Also from the same review:
- Labels that stack near each other must keep a minimum vertical gap — offset the
  text boxes, not the leader targets, so text never collides (Glass Frog "Guanine
  Crystal Surface" / "Mirrored Pouch" overlapped).
- The brand-green animated `callout` overlay type needs a semi-opaque dark backing
  plate that animates in/out with it — green-on-blue blended and was unreadable.

## Geography beats need a real map asset, sourced in research

Glass Frog scene 04: narrator says "southern Mexico to the Amazon basin" but the
visual is just a synthetic green zigzag line on black — no map. Tony: this is
common sense and a process gap.

**Rule:** whenever a script references a location, region, route, migration path,
or species range, the research phase (Production-Research-Agent) must
download/generate a suitable map asset and hand it to the motion-graphics build.
The assembly step must NOT fake geography with an abstract shape. A "map"
diagram type = real map base layer + animated path/marker overlay, never
path-only.

Lock into: Production-Research-Agent SKILL, Production-Asset-Planner SKILL,
Diagram-Generation SKILL, Anomalous_Wild_Video_Pipeline SKILL (Phase 5/6).
