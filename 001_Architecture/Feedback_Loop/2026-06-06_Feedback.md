# Feedback Log — 2026-06-06

## Validated Approaches

### Don't batch npm installs with native-dependency packages
When updating multiple global npm packages at once, packages with native deps (like hyperframes/sharp) can SIGKILL the entire install, leaving nothing updated. Install native-dep packages separately with `--ignore-scripts` as a last step.

### hyperframes requires --ignore-scripts
`npm install -g hyperframes@latest --ignore-scripts` is the correct install command. Without it, sharp's native build kills the process.

### Skip major version CLI upgrades unless intentional
typescript v6 was available but held at v5.9.3. Major version bumps on foundational tools like typescript should be deliberate decisions, not auto-updates.
