## Active Output Folders Must Contain Current Versions Only

For production artifact folders such as `Video_Clips`, Tony wants only the latest current version visible in the active folder. Older or superseded versions must be preserved in the matching `Archived/` folder, never left beside the current file.
## Seedance storyboard references must never be sent as start frames

The Shot 8 failure exposed a structural routing bug: the batch runner placed a
multi-panel storyboard URL in `first_frame_url`, causing Seedance to animate
the storyboard itself. A storyboard is contextual visual-continuity input and
must use `reference_image_urls`; `first_frame_url` is reserved for a clean
single-scene temporal starting state. The shared wrapper, Neon Parcel
pre-video gate, batch scripts, and regression tests now enforce this.

## Locked pipeline rules must be enforced in code, not left as prose for an agent to follow

Context: the 0003_Glass_Frog_Transparency loop-flash bug traced back to a "locked
2026-08-28" rule ("generate at the floor, then trim") that lived only as English
prose in three skill docs. No script enforced it; clip generation was done
freehand per beat. The planning agent set `generation_duration_s = target` for
every clip (the prose only covered sub-4s beats), assembly read the planned
number, and nobody trimmed.

Tony's feedback: "Why are these things overlooked continuously? The whole point
of locking things down is to make sure the rules are always followed. Whatever
process sends the prompt to the API needs to have everything hard-coded."

**Why it matters:** any pipeline step that depends on an agent remembering to do
it will eventually be skipped. A "locked" rule that isn't executable is not
actually locked.

**How to apply:** when a pipeline rule is locked, move it into a single
chokepoint function/script that every path must go through, add tests, and make
the surrounding tooling *refuse to run* without the required inputs. Docs then
describe what the code enforces, not what the agent should do. Done here:
`clip_durations.py` (padding + trim + short-footage guard, 17 tests) wired into
`pipeline_supervisor.py`, which now aborts if any video manifest entry lacks
`target_duration_s`.
