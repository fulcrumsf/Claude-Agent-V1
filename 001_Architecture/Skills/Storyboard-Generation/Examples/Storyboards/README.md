# Storyboard Examples

These images are reusable visual references for agents creating storyboards and downstream video prompts.

## How to Use Them

- Study the relationship between panels, action beats, camera framing, and continuity.
- Use them as examples of organization and visual communication, not as fixed templates.
- Preserve the active project's aspect ratio, naming rules, and approved storyboard format.
- Do not copy project-specific characters, locations, text, or story beats unless explicitly requested.
