## What was built / learned today
- **Scene prompt** (`room_slots.py`): print area is flat onion-skin orange (RGB 250,215,170); `presentation_for(room, decor, ratio)` picks frame / mat / canvas-in-natural-wood-floater (deterministic, weighted by decor). Grey and white inserts failed SAM; orange worked on 6/6 test scenes.
- **Canvas path:** `sam_detect(canvas=True)` / `build_psd(presentation="canvas")`: the printed face is the opening, pad 0. Tested on an oak-floater scene (SAM found the face; standard frame-lip rule cannot).
- **Ratio rule (Tony repeated it many times; NEVER add a ratio blocker back):** scale the art to cover (larger needed scale) and clip the overflow, never letterbox. Limits are now 35% (only absurd mismatches rejected). Memory: `feedback_ratio_mismatch_is_fine_cover_crop_2026-11-16.md`.
- **Orange placeholder** now in new PSDs (existing PSDs keep the grey grid until rebuilt).
- **Archive menu item** `POST /api/templates/archive` (moves PSD/preview/scene/sidecar/template.json into the folder's Archive; never deletes).
- **Gallery render bug (important):** the gallery sizes its test card from `so_px`, which comes FIRST from the "SO px" column in `Room_Templates/Directory.md`, then the manifest, then PhotoCraft's `exportContents` (which reports a wrong, larger size for assembled PSDs). A stale size gives an oversized displaced card. Whenever a smart object changes size, update the Directory.md row and the template.json `so_px`, then touch the PSD (the thumbnail cache is keyed on PSD size+mtime; agents cannot delete cache files).
- **Hand-fixed + shadow-rebuilt templates this session** (Tony resized the smart object in PhotoCraft and saved; Claude measured the corners from a black vs white card render and rebuilt black-fill shadow layers masked to the art): `LVRM_Trendy_Girl_5x7`, `LVRM_Trendy_Girl_4x5`, `003_BC_White_Bar_Cart` (wainscot panel scenes, approved), `LVRM_Modern_Cradenza_Angled_ISO` (smart object rebuilt to the frame's true ratio; stray brown speck erased from the Foreground Plant layer), `Modern_Moody_Beige` (old Reflections layer replaced by a measured "Room Light" dimming layer so the art matches the room's brightness; art extended to the frame). All pass the checker. Backups of every earlier version are in each folder's `Archive/`.

Claude cannot save from the live window. Then Claude: backs up, reads the quad, rebuilds shadows, runs the checker, sends a render.
