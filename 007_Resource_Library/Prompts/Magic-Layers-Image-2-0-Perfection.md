### CUSTOMIZABLE PROMPT:

Create a 16:9 documentary-style collage image using the attached reference sheet as the primary visual guide for style and composition.

**Subject:** \[INSERT SUBJECT\]

**Style & Composition:**

- Follow the reference sheet’s collage aesthetic: cut-out imagery, layered composition, vintage editorial feel
- All elements must have **soft, torn, or feathered edges**
- **No element should touch the edge of the canvas**
- Maintain wide, clean margins on all sides
- Use subtle paper texture, grain, and print imperfections
- Keep the layout balanced with a clear focal point and supporting elements

**Imagery:**

- Include a strong central subject
- Add supporting visual elements relevant to the subject
- Include human figures where historically appropriate
- Ensure all imagery matches a consistent vintage or archival tone

**Text:**

- Use **minimal text only**
- Maximum: one short headline and one small label (e.g. date or tag)
- No paragraphs, no detailed descriptions

**Colour Control:**

- Override the reference colour palette
- Primary colour: \[INSERT PRIMARY COLOUR\]
- Secondary colour: \[INSERT SECONDARY COLOUR\]
- Neutral tones: \[INSERT NEUTRALS\]
- Keep colours limited, consistent, and cinematic

**Graphic Elements:**

- Use subtle visual guides such as arrows, circles, underlines, or marks
- Apply sparingly to direct attention

**Constraints:**

- No modern elements or styles
- No clean digital edges — everything must feel tactile and aged
- Avoid clutter — prioritise clarity and hierarchy
- The final image should feel like a documentary frame, not a poster full of information
