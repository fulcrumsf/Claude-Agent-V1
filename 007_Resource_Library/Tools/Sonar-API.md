## Summary
Perplexity's Sonar API provides web-grounded chat completions using its Sonar models, offering real-time, citation-backed answers by blending advanced reasoning with live web data. It allows developers to integrate generative search capabilities into applications for factual accuracy and up-to-the-minute information retrieval. The Sonar API is being supported until September 27, 2026, as it transitions to the Agent API.
