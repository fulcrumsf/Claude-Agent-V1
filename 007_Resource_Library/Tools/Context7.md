## Summary
Context7 is an MCP (Model Context Protocol) server that provides up-to-date, version-specific documentation and code examples for large language models (LLMs) and AI code editors. It aims to reduce AI hallucinations by injecting relevant, current information directly into the AI's context window from official sources.
