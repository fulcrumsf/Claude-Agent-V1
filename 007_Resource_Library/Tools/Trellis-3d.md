## Summary
TRELLIS is a Microsoft open-source project and a large 3D asset generation model. It creates high-quality 3D assets from text or image prompts, utilizing a unified Structured LATent (SLAT) representation. The model can output 3D assets in multiple formats, including meshes, radiance fields, and 3D Gaussians, and supports local editing capabilities.
