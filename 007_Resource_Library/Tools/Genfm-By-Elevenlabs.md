## Summary
GenFM is a feature within ElevenLabs' Studio that enables users to automatically transform various content formats, such as PDFs, articles, and eBooks, into dynamic podcasts. It utilizes lifelike AI voices, including co-hosts, to narrate and discuss the provided source material. This tool is designed for generating long-form spoken-audio content from scripts or source material.
