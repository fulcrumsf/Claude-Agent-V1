## Summary
YuE is an open-source GitHub project that provides a series of foundation models for full-song music generation. It transforms lyrics into complete songs, including vocal and accompaniment tracks, and can generate music up to five minutes long. The project supports diverse genres, languages, and vocal techniques, and is built on the LLaMA2 architecture.
