## Summary
Rork is an AI app builder that converts plain-English text descriptions into functional mobile and web applications. It offers two main products: Rork (Standard/Pro) which uses React Native and Expo for cross-platform iOS, Android, and web apps, and Rork Max which generates native Swift apps for the Apple ecosystem. The platform allows for rapid prototyping, iteration on features, and export of production-ready codebases, with support for App Store and Google Play publishing.
