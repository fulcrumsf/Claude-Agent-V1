## Summary
Galileo AI, now integrated into Google Stitch, is an AI-powered UI/UX design tool that generates user interface concepts for web and mobile applications from text or image prompts. It enables rapid screen generation, exploration of layout variations, and can export designs to Figma or as front-end code.
