## Summary
LemonSlice is an AI research and product lab that develops 'Character World Models' to create real-time, interactive AI avatars from a single image. These avatars can talk, listen, and react, offering full-body movement, hand gestures, and emotional expressions. The technology is available via an API and an embeddable widget for applications in customer support, education, and entertainment.
