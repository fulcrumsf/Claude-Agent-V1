## Summary
Magic Patterns is an AI design tool that enables product teams to generate high-fidelity UI prototypes from prompts, product requirements, or feature ideas. It integrates with existing design systems to create on-brand, interactive prototypes and supports real-time collaboration. The tool can export designs to Figma or provide production-ready code.
