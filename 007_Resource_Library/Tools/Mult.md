## Summary
Mult.dev is a web and mobile application that allows users to create animated travel map videos. It enables the creation of custom routes, importing GPS files (GPX, KML, GeoJSON), adding photos to stops, and selecting various transportation modes. The tool is designed for generating engaging travel stories for social media platforms like Instagram, TikTok, and YouTube.
