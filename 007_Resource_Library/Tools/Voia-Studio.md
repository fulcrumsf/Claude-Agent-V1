## Summary
Voia is an AI-powered virtual production platform that automates filmmaking workflows. It integrates live-action footage, generated videos, and CGI, enabling artists to create high-quality visual effects and 3D environments using tools like iPhones, without the need for green screens. The platform supports the creative process from pre-visualization to final rendering.
