## Summary
Tooooools.app is a free, web-based tool for applying lo-fi visual effects to images and videos. Users can upload media files and apply various effects such as dithering, halftone patterns, gradients, distortions, and ASCII art. It is created by Daniil Sukhovskoy and is available for both personal and commercial use without requiring sign-up.
