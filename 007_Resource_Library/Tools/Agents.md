## Summary
Agents.Sabrina is a free, crowdsourced library offering over 1000 curated AI agent and automation templates for platforms like n8n and Make. It serves as a resource for users to browse real-world use cases, gain inspiration, and quickly implement ready-made AI workflows for content, operations, and development tasks. The platform provides JSON templates for easy import and aims to be a beginner-friendly resource for building AI agents and automations.
