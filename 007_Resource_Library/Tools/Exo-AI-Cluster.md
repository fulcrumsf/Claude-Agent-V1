## Summary
EXO is an open-source project that enables users to build local AI inference clusters by connecting multiple devices, primarily Apple Silicon Macs, to run large language models. It automatically discovers devices, partitions models across their combined memory, and provides an OpenAI-compatible API for distributed inference. The project aims to make frontier AI models accessible locally without requiring expensive cloud services or single high-end GPUs.
