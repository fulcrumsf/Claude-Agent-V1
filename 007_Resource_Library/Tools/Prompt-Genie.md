## Summary
Prompt Genie is a Chrome extension and web tool designed to optimize AI prompts. It transforms basic AI requests into detailed, structured 'Super Prompts' for platforms like ChatGPT, Claude, and Gemini, aiming to produce better and more consistent results. The tool also includes features for organizing prompts, saving contexts, and learning user preferences over time.
