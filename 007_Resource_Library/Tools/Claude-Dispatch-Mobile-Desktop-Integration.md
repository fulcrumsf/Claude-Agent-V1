This image provides a definition of Claude Dispatch, a feature within the Claude Cowork system that allows users to securely assign and monitor tasks from a mobile device to the Claude Desktop app. It explains how the feature bridges mobile and desktop environments to enable remote control of AI agents for tasks like reading files and drafting emails.
