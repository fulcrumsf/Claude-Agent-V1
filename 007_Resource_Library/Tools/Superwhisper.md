## Summary
Superwhisper is an AI-powered voice-to-text application available for macOS, Windows, and iOS. It offers highly accurate dictation with both offline and cloud speech recognition, supporting over 100 languages. The tool includes features like custom AI modes for intelligent formatting, filler word removal, and meeting transcription, integrating seamlessly with various applications.
