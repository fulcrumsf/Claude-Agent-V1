## Summary
n8nChat is an AI-powered browser extension for n8n that enables users to create, edit, debug, and optimize n8n workflows using natural language. It integrates directly into the n8n workflow editor, allowing users to generate nodes and complete workflows from chat prompts. The extension is available for Chrome and Firefox and requires the user's own AI service API key.
