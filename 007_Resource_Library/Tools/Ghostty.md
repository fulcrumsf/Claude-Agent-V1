## Summary
Ghostty is a fast, feature-rich, and cross-platform terminal emulator that utilizes platform-native UI and GPU acceleration. It is an open-source project available for macOS and Linux, designed to provide a native application experience. The project also includes `libghostty`, a cross-platform C and Zig library for building terminal emulators.
