## Summary
AgentGPT is a browser-based platform by Reworkd AI that enables users to create and deploy autonomous AI agents for various tasks. Users can define an agent's name and objective, and the agent will break down goals into subtasks, execute them, and learn from the results. Although the hosted site is still operational, the open-source project was archived in January 2026 and is no longer actively maintained.
