## Summary
N8N Workflows Catalog (n8nworkflows.xyz) is a website that serves as a browsable interface for a large, open-source collection of n8n automation workflows, primarily hosted on a GitHub repository. This resource provides a directory of ready-to-adapt n8n workflow templates and automation examples for various common tasks.
