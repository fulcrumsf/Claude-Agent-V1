## Summary
n8n is an open-source workflow automation platform that allows users to build automated processes by visually connecting various applications, APIs, and data sources. The n8n.io/workflows/ page provides a collection of pre-built workflow templates that users can import and customize to automate tasks across different business areas. These templates help streamline operations by offering ready-to-use automation sequences for common use cases.
