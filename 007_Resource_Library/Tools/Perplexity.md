## Summary
Perplexity AI is an American privately held software company offering an AI-powered search and answer engine. It uses large language models and real-time web search capabilities to provide direct, conversational responses to user queries with citations. The platform also offers a Pro subscription with advanced features and has developed AI agents like Perplexity Computer for multi-step tasks.
