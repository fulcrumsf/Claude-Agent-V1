## Summary
Cursor Directory is a community-driven online platform that serves as a catalog for plugins, tools, and resources designed to enhance the Cursor AI-assisted code editor. It allows developers to discover and submit extensions, rules, and integrations that improve AI-assisted app development workflows within the Cursor IDE. The platform also includes a security scan for submitted plugins.
