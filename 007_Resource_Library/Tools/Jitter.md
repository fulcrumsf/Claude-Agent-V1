## Summary
Jitter is a web-based motion design tool that enables users to create professional animations quickly and easily, often referred to as the 'Figma of Motion Design'. It is used for animating text, UI-style animations, social graphics, and website sections. Key features include animation presets, seamless integration with Figma, and export options for video, GIF, and Lottie files.
