## Summary
Kolors Virtual Try-On is a public Hugging Face demo from the Kwai-Kolors project that combines a person image and a garment image to synthesize a visual try-on result. This AI-powered tool is used to preview how clothing might look on a person, useful for e-commerce visuals, styling experiments, and rapid concepting.
