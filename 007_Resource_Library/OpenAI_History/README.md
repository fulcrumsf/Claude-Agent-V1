# OpenAI History

This folder is the conversation layer.

## What Lives Here
- Readable `.md` conversation files
- Theme-based conversation organization
- Links to images and other assets

## What Does Not Live Here
- Canonical image binaries
- Visual asset notes
- Duplicate copies of attachments

## How To Use It
- Use this folder when you want to find the conversation where something happened.
- Use the links inside the `.md` files to jump to image assets in `Obsidian_Attachments`.
- Treat this folder as the searchable history of what was said and done.
