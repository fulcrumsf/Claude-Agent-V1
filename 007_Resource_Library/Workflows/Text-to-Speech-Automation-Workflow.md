## Summary
A visual workflow diagram displaying a process chain that converts text to speech. The workflow includes nodes for manual input data, a specific 'Convert text to speech' action using a TTS model, and subsequent HTTP requests sending the audio to an API endpoint (visible as wav2speak). This captures an automation pipeline for generating speech from text.
