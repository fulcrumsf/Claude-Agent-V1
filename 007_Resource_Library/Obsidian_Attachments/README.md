# Obsidian Attachments

This folder is the visual asset library.

## What Lives Here
- Image binaries
- Other attachment files used by notes
- Canonical asset files for visual search and reuse

## What Does Not Live Here
- Conversation transcripts
- Theme notes
- Narrative summaries of the conversation history

## How To Use It
- Use this folder when you want to find images by topic, style, or use case.
- Each important image should have a matching note in `007_Resource_Library/Research/OpenAI_Images/`.
- Treat this folder as the source of truth for visual assets.
