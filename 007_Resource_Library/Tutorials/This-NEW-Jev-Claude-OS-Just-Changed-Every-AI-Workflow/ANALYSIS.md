### 3. Jev 3-Tier Routing Architecture (`005_architecture_jev.jpg` & `006_voice_routing.jpg`)
- **The Bridge:** Single orchestrator connecting HUD / Obsidian plugin to local voice and vault storage.
- **Jev Classifier:** Classifies incoming natural language prompts across 3 execution tiers:
  - **Tier 1 (Instant / No AI):** Deterministic rules, local retrieval, file lookups, internal Obsidian commands (<1ms execution). Example: "What are my priorities?", "Bring up morning brief".
  - **Tier 2 (Quick Answer / Fast LLM):** Lightweight models (Haiku / Luna / local small LLMs) for fast summaries. Example: "Summarize today's AI news".
  - **Tier 3 (Real Work / Deep Agent):** Spawns terminal agent session (Claude Code or Codex) or headless background skill to perform multi-step file manipulation, coding, or report generation.
- **Jev vs. Standard LLMs:** Evaluates probabilities across predefined choices (e.g. 92% Billing, 5% Technical, 3% Sales) 200x faster and cheaper than generating conversational text.

### 4. Skill Backbone & Automation Matrix (`007_skills_backbone.jpg`)
- **Hierarchy:** `Domain` (life/business area) → `Task` (repetitive action) → `Skill` (documented prompt/procedure executed by agent) → `Automation` (scheduled or event-triggered execution).

- **Golden Rules of Thumb:**
  1. *Done it by hand twice* → Make it a skill.
  2. *Skill works 5 times in a row* → Automate it (schedule / webhook / file watcher).
  3. *It sends, spends, or publishes* → Keep it manual with human-in-the-loop review.
