Here is my video script with timestamps. I want you to use Higgsfield with the gpt_image_2 model to generate one image for each timestamp. Every image must be horizontal in a 16:9 format. Each image should match the exact idea being said at that moment in the script and visually explain it in a clear, simple, and easy-to-understand way.

Please name every image with the exact timestamp from the script, so I know exactly where to place it in the video.

The style of the generated images should look like clean editorial explainer visuals, mixed with paper-style layouts, text, and simple supporting graphics. The images should feel like polished educational slides or explainer frames, not cinematic 3D character scenes. They should directly show what the current timestamp is saying.

Use a clean white or very light paper-like background. The overall design should feel premium, minimal, educational, trustworthy, and easy to read. Use black text as the main text color, with orange used only as a highlight color for emphasis, arrows, icons, key words, small accents, charts, callouts, or important details. Keep the visuals uncluttered and spacious.

The layout style should be inspired by modern editorial explainer graphics: paper textures, soft gradients, subtle collage or layered-paper details, clean typography, simple icons, labels, arrows, boxes, charts, callouts, and minimal visual elements that help explain the point. You can include paper cards, sticky-note style elements, graph blocks, simple infographics, diagrams, document shapes, UI boxes, thumbnails, timelines, or charts when they fit the idea being explained. The design should feel like an educational motion-graphics frame, not like a poster packed with too much information.

Typography should be clean, bold, and readable. Headlines should be strong and easy to scan. Body text should stay short, clear, and simple. You may use a handwritten or pen-style accent only occasionally for emphasis, but the main style should remain clean and professional. Do not overload the frame with too much text. Only include the most important words, phrases, or labels needed to explain the current timestamp.

Each image should focus on one clear idea only. It should show exactly what the current timestamp says, using a mix of text and supportive graphics. The goal is not to create decorative visuals, but visuals that improve understanding. Every element on screen should help explain the script.

The style should follow these rules:

* Use the gpt_image_2 model
* Every image must be horizontal 16:9
* White or very light background
* Black text first
* Orange only for highlights and emphasis
* Clean and minimal layout
* Easy-to-read typography
* Subtle paper or editorial design feel
* Simple charts, icons, arrows, labels, and callouts
* Not too cluttered
* Clear educational explainer style
* Premium and trustworthy look
* No logos or branding from other companies or media brands
* Do not include the word “Vox” or any Vox logo anywhere in the images
* No visual artifacts
* No glitches
* No distorted text
* No broken shapes
* No messy or low-quality elements

Avoid dark backgrounds, overly flashy visuals, noisy textures, crowded layouts, overly colorful designs, generic stock-looking compositions, visual artifacts, glitches, distorted text, or broken design elements. Avoid making every image look the same. The layout system and style should stay consistent, but the content of each frame should change depending on the timestamp.

For each timestamp, first understand the exact point being made in the script. Then generate the most relevant explainer-style frame in this paper/editorial design style, using text and graphics to show exactly what that timestamp is about.
