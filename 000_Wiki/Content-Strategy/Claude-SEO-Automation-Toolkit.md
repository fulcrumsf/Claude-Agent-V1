# Claude SEO Automation Toolkit

## What It Is
This is an AI SEO workflow built around Claude Code and the DataForSEO API. It automates audits, keyword research, competitor analysis, backlink checks, and PDF report generation from a single command.

## Key Concepts
- Real SEO data instead of scraped guesses
- One command can produce client-ready reporting
- The workflow is framed as agency-grade deliverable generation
- Useful for local businesses, agencies, and productized SEO offers

## How Tony Uses This
Use this when Tony wants to package SEO as an AI-assisted service or quickly assess a site's search visibility without manual spreadsheet work. It is a strong pattern for productized consulting offers.
