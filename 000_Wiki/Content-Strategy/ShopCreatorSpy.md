# ShopCreatorSpy

## What It Is
ShopCreatorSpy is a TikTok Shop competitive intelligence tool that reverse-engineers winning videos. It scores hooks, identifies formats, and produces a step-by-step action plan based on real engagement data.

## Key Concepts
- Hook scoring from 0 to 100
- Breakdowns of hook type, format, and sell ratio
- Real engagement data drives the recommendations
- The output is meant to be directly actionable for copycat-free iteration

## How Tony Uses This
Use this when Tony wants to study what is working in TikTok Shop before making his own content. It is especially useful for identifying patterns that can be adapted rather than blindly copied.
