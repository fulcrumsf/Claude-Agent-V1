# Beehiiv MCP

## What It Is
beehiiv MCP is a Model Context Protocol integration that connects a beehiiv account to AI clients like Claude, ChatGPT, and Gemini. The first version is read-only and is aimed at turning newsletter data into something an AI can actually inspect and reason over.

## Key Concepts
- Direct access to newsletter data instead of copy-pasting exports into chat
- Read-only access first, with write access planned later
- Useful for subscriber analysis, churn investigation, sponsor research, and performance review
- Sits alongside other beehiiv product updates like Signup Flows and the Website Dashboard

## How Tony Uses This
Use this when Tony wants AI to inspect newsletter performance or help reason about audience behavior without manual data wrangling. It is especially relevant if beehiiv is part of the content or email stack and Tony wants an AI layer on top of it.
