# Hermes Agent

## What It Is
Hermes Agent is an open-source autonomous agent system designed for persistence, memory, and closed learning loops. The desktop app makes the workflow easier by putting the agent into a native UI instead of leaving everything in the terminal.

## Key Concepts
- Persistent cross-session memory
- Self-improving skill creation from completed tasks
- Multi-agent orchestration and long-running workflows
- Desktop UI lowers friction for non-terminal use
- Can be run on your own infrastructure with your own model provider

## How Tony Uses This
Use this as a reference when Tony wants a more autonomous agent shell than a normal chat interface. It is relevant to memory-heavy workflows, long-running task automation, and systems that learn from prior runs.
