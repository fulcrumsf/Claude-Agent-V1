# Blotato Claude Skills

## What It Is
This is a small skill stack for going from a blank page to a scheduled social post inside Claude. The workflow centers on `content-coach`, which can call `brand-brief`, `post-writer`, `post-grader`, and `post-scheduler` as needed.

## Key Concepts
- One front-door skill handles ideation and routes the rest
- Brand brief creation is treated as a one-time setup step
- Drafting and grading loop until the post reaches a good score
- Scheduling is the final handoff to Blotato
- The same skill files work in Claude Code, Claude Desktop, and Claude Cowork

## How Tony Uses This
Use this when Tony wants a repeatable social-post workflow inside Claude without bouncing between separate tools. It is especially useful for content systems that need brand context, copy drafting, and scheduling in one chain.
