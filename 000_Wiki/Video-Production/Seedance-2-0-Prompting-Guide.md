# Seedance 2.0 Prompting Guide

## What It Is
Seedance 2.0 works best when prompted like a director. The guide emphasizes structured shot lists, multi-shot pacing, native audio, and clear separation between reference use and direct editing.

## Key Concepts
- Write prompts as shot scripts, not as loose descriptions
- Specify shot count, duration, aspect ratio, and escalation arc
- Use sequential beats so the model understands motion and timing
- Reference and edit are different intents and should be named explicitly
- Seedance also works as a multimodal reference system with image, video, audio, and text inputs
- Reference assets can drive motion, camera work, character consistency, and creative template replication
- Strong prompts include physics, motion, lighting, and negative constraints

## How Tony Uses This
Use this as the main prompt-writing reference when Tony is building cinematic AI video, especially where scene progression and camera language matter. It is ideal for reusable prompt templates and prompt packs.
