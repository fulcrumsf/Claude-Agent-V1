# Annotation Prompts

## What It Is
Annotation prompts are visual instructions added directly onto a reference image, such as arrows, boxes, labels, or movement notes, so an AI image or video model can understand how objects should move or behave in a generated scene.

## Key Concepts
- Visual prompting uses an existing image as part of the instruction, not just written text.
- Arrows can communicate direction, speed, path, or intended motion.
- Boxes and labels can identify which object should change, move, or remain fixed.
- The technique is especially useful when text alone is too vague for spatial movement.
- Annotation prompts can improve image-to-video workflows by making object actions clearer before generation.

## How Tony Uses This
Use this in the Video Editor pipeline when building scene references for image-to-video shots, especially Veo-style generations where object movement matters. It fits storyboard preparation, motion planning, and prompt pack creation before sending assets into kie.ai or another video generation tool.
