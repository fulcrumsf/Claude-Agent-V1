# OpusClip Agent Opus Affiliate Program

## What It Is
This is the partner and affiliate program for OpusClip and Agent Opus, with Rewardful-based dashboard access, monthly payouts, and media kit support for promotion.

## Key Concepts
- Rewardful is the affiliate dashboard layer
- Payouts happen on the 15th of each month
- The media kit is the main promotional reference
- Agent Opus broadens the product from clipping into idea-to-video workflows

## How Tony Uses This
Use this when Tony wants to promote or evaluate short-form video tooling that can be monetized through affiliate revenue. It is also useful for understanding how clip-and-post tools position themselves in the market.
