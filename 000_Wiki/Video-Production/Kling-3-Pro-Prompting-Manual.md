# Kling 3 Pro Prompting Manual

## What It Is
This is a working prompt manual for Kling 3.0 Pro that treats the model like a cinematic intent engine. The emphasis is on structured shots, native audio, motion physics, and precise subject/element binding.

## Key Concepts
- Kling supports multi-shot prompts and benefits from explicit sequencing
- Native audio belongs in the prompt, not as an afterthought
- Motion should be described with physics and motivation, not just adjectives
- Time-coded sequencing and micro-adjustments are the key to better outputs
- Iteration should change one variable at a time

## How Tony Uses This
Use this when Tony wants to write production-grade Kling prompts for action, dialogue, motion, or transformation scenes. It is one of the strongest references here for serious video generation work.
