# Ecamm Live Streaming Tool

## What It Is
Ecamm is a Mac-based live streaming and recording tool that combines camera switching, screen sharing, HDMI capture, prerecorded video playback, and iOS/DSLR input support. It is positioned as an all-in-one production surface.

## Key Concepts
- Built for streaming, recording, podcasting, and presenting
- Supports multiple camera and screen sources
- Can roll pre-recorded assets into a live session
- Handles system audio and on-screen windows
- Useful when the production needs to stay on the Mac and remain simple

## How Tony Uses This
Use this when Tony wants to broadcast, record a talk, or create a live production setup without assembling a full broadcast stack. It is useful for tutorials, interviews, and screen-based demo content.
