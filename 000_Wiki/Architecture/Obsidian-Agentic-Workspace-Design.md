# Obsidian Agentic Workspace Design

## What It Is
This is a pattern for turning Obsidian from a passive note vault into an agent-driven workspace. The workflow uses local terminal agents, custom plugins, embedded web views, Dataview, Canvas, and workspaces to reduce manual note-taking and surface the right context automatically.

## Key Concepts
- Local files stay on the machine, which keeps the system portable
- Terminal agents can write to daily notes and route structured data
- Dataview and Canvas turn notes into operational dashboards
- Embedded web apps and sidebars make the vault a control center, not just a notebook
- Custom plugin work can be generated with AI instead of hand-built from scratch every time

## How Tony Uses This
Use this as the architecture reference when Tony wants Obsidian to act as the system of record for workflows, daily logs, dashboards, and automation hooks. It is especially relevant when wiring the vault into Claude Code or other local agents.
