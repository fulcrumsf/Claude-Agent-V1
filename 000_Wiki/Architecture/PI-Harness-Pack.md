# PI Harness Pack

## What It Is
PI Harness Pack is a small tool/reference bundle for setting up and understanding PI with OpenRouter and the surrounding harness structure. It is not a polished app; it is a working pack of setup notes, auth configuration guidance, and architecture direction.

## Key Concepts
- PI setup and local config
- OpenRouter auth and default provider routing
- Harness architecture and operator-layer thinking
- Practical setup-first documentation instead of product polish

## How Tony Uses This
Use this as the starting reference when Tony wants to evaluate or adapt PI for future workflows. Keep the source pack together in `007_Resource_Library/Tools/PI-Harness-Pack/`.
