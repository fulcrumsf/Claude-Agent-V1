# Astro Cloudflare Website Builder

## What It Is
This is a modern website-building stack that uses Astro, Tailwind, MDX, Cloudflare Pages, Wrangler, and GitHub to replace heavier WordPress + Elementor workflows with a static-first system that is easier to maintain.

## Key Concepts
- Astro gives the site fast page delivery with minimal client-side JavaScript
- Cloudflare Pages handles deployment with simple, global hosting
- Wrangler is the CLI surface for deployment and Cloudflare access
- MDX and content collections make the site easier to author and scale
- The stack is aimed at content creators and blog-style websites that need speed and maintainability

## How Tony Uses This
Use this when Tony wants to plan or build a fast personal or brand website, especially when the goal is to move away from WordPress and into a more agent-friendly static stack.
