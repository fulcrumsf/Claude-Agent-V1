# Magnific API

## What It Is
Magnific is an API platform for text-to-image, text-to-video, image editing, video generation, icon generation, classifier APIs, and stock content. The docs position it as a broad creative API surface rather than a single-purpose endpoint.

## Key Concepts
- One API family covers several creative generation tasks
- Image editing, upscaling, relighting, and transformation are first-class use cases
- Video and image workflows can be composed from the same platform
- The documentation starts from an index, which makes discovery important

## How Tony Uses This
Use this when Tony needs a creative API reference that spans generation and editing, or when comparing Magnific against other image/video toolchains. It fits especially well into content and video-production workflows.
