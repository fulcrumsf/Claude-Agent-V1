# Plan 04-02: Enforce Handoff at the Pre-Video Gate

## Objective

Make the existing provider-free pre-video gate require validated storyboard evidence for the storyboard route and preserve first-frame/reference-role separation.

## Requirements Covered

- HANDOFF-01
- HANDOFF-02
- HANDOFF-03

## Must Haves

1. Seedance storyboard-route validation requires a passing selected storyboard manifest.
2. A blocked/manual-review storyboard cannot pass the gate even when other scene gates pass.
3. A storyboard cannot be placed in `first_frame_url`, and a clean first frame cannot be confused with the storyboard reference.
4. Existing non-storyboard routes remain compatible and continue to use their current requirements.
5. Regression tests prove the gate blocks invalid handoffs before the provider wrapper is reached.

## Tasks

### Task 1: Extend pre-video validation
- Add selected-storyboard-manifest validation to the storyboard route.
- Compare manifest paths/hashes to the supplied reference asset and prompt package where available.
- Keep all failures auditable and actionable.

### Task 2: Wire shared provider boundary
- Ensure the handoff payload uses `reference_image_urls` for the selected storyboard.
- Preserve `first_frame_url` only for a clean temporal start image.
- Confirm the shared Kie wrapper remains a second defense, not the only defense.

### Task 3: Update operational documentation
- Update Neon Parcel and Seedance guidance with the full order: contract → candidate generation → QA → capped retries → selected manifest → pre-video gate → Seedance.
- Document the no-paid-call dry-run path.

## Verification

- Run the full focused Neon Parcel test suite plus existing wrapper tests.
- Test valid selected-pass handoff and invalid blocked/manual-review handoffs.
- Confirm no network call occurs during gate validation.
