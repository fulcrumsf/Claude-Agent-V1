# Plan 01-01: Define Storyboard Contract

## Objective

Create the versioned, machine-readable storyboard contract and prompt builder that all future storyboard candidates will use.

## Requirements Covered

- STORY-01
- STORY-02
- STORY-03

## Must Haves

1. A required schema captures overall summary, visual/camera locks, continuity invariants, ordered frame specifications, exact captions, and hard constraints.
2. Validation rejects incomplete frames and missing continuity-critical fields before any image-generation call.
3. Prompt rendering emits a stable labeled structure for every shot.
4. A Shot 6 fixture encodes the closed-gate and subject-presence continuity that failed in v1.
5. Unit tests cover valid serialization, invalid omissions, exact caption preservation, and stable section ordering.

## Tasks

### Task 1: Define the contract
- Inspect existing storyboard and shot-list artifact shapes.
- Add a focused schema/validation module in the Neon Parcel tool area.
- Keep the schema provider-neutral and make required versus optional fields explicit.

### Task 2: Build the prompt renderer
- Render the stable sections in the locked order.
- Render every frame as a numbered, explicit instruction with its caption adjacent to the frame.
- Include hard constraints that forbid unexplained subject/object appearance and state changes.

### Task 3: Add regression fixtures and tests
- Add the Shot 6 structured fixture.
- Test that the fixture expresses bear presence, grandmother presence/entry, gate state, and opening direction across frames.
- Test that missing or contradictory fields fail before provider invocation.

### Task 4: Document handoff assumptions
- Record the schema and artifact filenames in the relevant Neon Parcel skill/tool documentation.
- State that Phase 2 consumes the same contract for visual comparison.

## Dependencies

- Existing `Storyboard-Generation` and Neon Parcel skill conventions.
- Existing JSON artifact and test patterns.

## Verification

- Run the focused Neon Parcel unit-test suite.
- Run `py_compile` on new/changed Python modules.
- Inspect a rendered Shot 6 prompt and verify every frame is explicit and captioned.
- Confirm no provider/network call is made by schema validation or prompt rendering tests.
