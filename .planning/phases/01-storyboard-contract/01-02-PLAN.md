# Plan 01-02: Contract Review Gate

## Objective

Review the contract against real production failure cases before Phase 2 implementation begins.

## Requirements Covered

- STORY-01
- STORY-02
- STORY-03

## Must Haves

1. The contract can represent the Shot 6 sequence without ambiguity.
2. The rendered prompt makes it possible for a later checker to compare each panel to a known expected state.
3. Any field that cannot be verified visually is identified as an explicit limitation rather than silently treated as true.

## Tasks

### Task 1: Static review
- Compare the rendered contract/prompt to the existing Shot 6 source prompt and storyboard artifacts.
- Confirm the new structure separates intended action from observable frame state.

### Task 2: Acceptance checklist
- Write a short checklist for Phase 2: subject presence/count, object state, action transition, spatial continuity, physics, captions, and ambiguity handling.
- Mark which checks are deterministic from schema and which require vision evidence.

### Task 3: Plan handoff
- Update Phase 2 planning inputs with the checklist and any contract gaps found.

## Verification

- Human review of the rendered Shot 6 contract.
- Test that the acceptance checklist maps to explicit schema fields.
- No paid generation.
