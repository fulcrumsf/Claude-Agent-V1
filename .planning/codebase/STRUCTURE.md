# Structure

## Workspace Areas
- `001_Architecture/`: shared maps, skills, tools, scripts, memory, and logs.
- `002_Content-Creation/`: channel-specific productions and media.
- `007_Resource_Library/`: durable references and tutorials.
- `.planning/`: GSD project context and execution plans.

## Neon Parcel Locations
- Skill contract: `001_Architecture/Skills/Neon_Parcel_Longform_Compilation/SKILL.md`.
- Generic storyboard contract: `001_Architecture/Skills/Storyboard-Generation/SKILL.md`.
- Seedance prompt contract: `001_Architecture/Skills/Seedance-Prompting-Guide/SKILL.md`.
- Channel tools: `001_Architecture/Tools/Video-Generation/Channels/Neon_Parcel/`.
- Active production: `002_Content-Creation/Video_Editor/002_Channels/002_Neon-Parcel/Productions/0001_Grandma-And-Bear-Compilation/`.

## Artifact Layout
Productions separate prompts, images, active clips, archived clips, working/intermediate media, package output, and JSON decision/history data. Versions remain traceable by shot ID and version number.

## Naming
Workspace files use Title-Case-With-Dashes or the established uppercase data names; Python scripts are snake_case. Production media uses shot/version identifiers and archived folders preserve superseded iterations.
