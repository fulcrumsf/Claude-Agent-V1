# Portal — Directory

Local Ikigai portal + listing pipeline (FastAPI, SQLite, Docker). Input: `../Ikigai_Portal_Pipeline_Brief.md`.

- `app/` — web app (`main.py`), idea pool logic (`ideas.py`), engine list (`engines.py`), `pipeline/` step stubs
- `config/` — engines, print sizes (unverified placeholders), pipeline steps, settings
- `tests/` — pytest
- `data/` — local DB and output (git-ignored)
