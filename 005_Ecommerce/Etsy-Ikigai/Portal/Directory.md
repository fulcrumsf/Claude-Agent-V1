# Portal — Directory

Local Ikigai portal + listing pipeline (FastAPI, SQLite, Docker). Input: `../Pipeline_Docs/Ikigai_Portal_Pipeline_Brief.md`.

- `app/` — dashboard shell (`main.py`), Ikigai Studio module (`studio.py`), idea pool logic (`ideas.py`), taste profile (`taste.py`), chat window (`chat.py`), chat brain via headless Claude CLI with validated dashboard actions (`assistant.py`), sales channels (`channels.py`), research import CLI (`import_ideas.py`), image engines on kie.ai (`engines.py`), stage 2 idea-to-art (`art.py`: style cards, prompt writer, rounds, picks, approval, oversight log), stage 3 upscale + resize for the Art tab (`prints.py`), `pipeline/` step runner + steps (generate_art check, upscale, resize, mockups built; package / listing_text / etsy_draft still stubs); Production tab (stage 4, 2026-11-08): `production.py` (cards, tags, one job at a time, Archive moves), `room_slots.py` (slot plan + art-to-room compatibility + ratio weights), `scene_templates.py` (AI scene -> insert corners -> PhotoCraft PSD -> auto-saved template; manifests for Tony's PSDs)
- `data/Taste_Profile.md|json` — auto-written taste profile the research job reads (git-ignored with the DB)
- `config/` — engines (kie.ai models, credits, default), style cards + chip groups (`style_cards.json`), print sizes (verified 2026-11-05 against 00120 Pastel Waves), pipeline steps, settings
- `tests/` — pytest
- `data/` — local DB and output (git-ignored); generated art in `data/art/<idea_id>/`, upscaled masters in `data/upscaled/<idea_id>/` (both made at runtime)
- `../Designs/<NNNNN>-<Name>/01-Printables/` — the 5 print JPGs written by the resize step (one folder per design)
- 2026-11-10 build (Ikigai_Portal_Build_Plan_2026-11-10): slot map rooms = 3 + 9-19 (`room_slots.ROOM_SLOTS`, settings `room_slots`; fixed 1, 2, 8 rendered + 4-7, 20 copied by `mockups.py`); cover-fit art (`scene_templates.fit_cover`, >3% crop refused, native smart-object size read from the PSD); new AI templates get black-fill shadows (`Light Shadow` from the measured sun line or falloff, `Frame Edge Shadow`); `template_checker.py` (headless read-only checker, results `config/template_checks.json`; Production auto-picks skip FAIL templates); `template_build.py` (Templates tab "Build this" into an empty gap folder, ~18 credits per click; proposed room folders Entryway/Laundry created only on Tony's click); `template_edit.py` (Edit with chat on a working copy in `data/rooms/Edit_*`, Save archives the old PSD; Open in PhotoCraft with control port 47811 + token file); `sam_frames.py` (SAM 2 prototype, runs only with the `~/.cache/ikigai-sam` venv)

- 2026-11-11 SAM precision build (Tony's "pixel-perfect" standard): `app/sam_frames.py` (SAM 2.1 hiera large in `~/.cache/ikigai-sam`, run as a subprocess by `scene_templates.sam_detect`; geometry helpers are numpy/cv2 and imported directly) gives every NEW template its corners and masks; `scene_templates.build_psd` = SAM corners + measured lip/key-light black-fill shadows with real layer masks + black/white `card_verify` (<= 1 px); the old brightness/Canny `find_insert` is legacy (tests only). Checker opening check uses SAM (`template_checker.sam_opening`, fallback = old edge search; never on BDRM_Wabi_Vertical) and SAM's wall mask for the sun line. `app/kie_edit.py` = the generation helper copied from the archived Teak Sideboard (settings `kie_edit_script`). `room_templates.rooms()` ignores anything inside `Archive/`. Tests: `tests/conftest.py` fakes SAM + card test; `tests/test_sam_frames.py` tests the geometry for real. Staged templates waiting for a folder: `data/rooms/Staged_<Name>_*` (git-ignored).
- 2026-11-15: `app/wide_fill.py` = generative fill, wide-crop method (Nano Banana 2.1 on kie.ai, 6 credits) for Edit with chat pixel edits; Portal copy of OpenFill's `_agentos_wide_fill` (OpenFill keeps its own in its install). SAM 3.1 text search via `001_Architecture/Tools/Image-Generation/photocraft_sam_select.py` (ComfyUI). Working files `data/rooms/Edit_<key>_base_v*.png`, `_fill_v*_crop.png`, `_fill_v*_answer.png`, `_base_edit_v*.png`. Editor renders with the amber card (`Edit_tint_*.png`). Open in PhotoCraft = OpenFill build (port 7878). Tests: `tests/test_wide_fill.py`.
